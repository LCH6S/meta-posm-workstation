## 当前范围与规则

- Meta POS 首页 → 电子发票 → 开票 / 退票 / 开票记录。模块首页无门店信息，一行一个白色功能卡片。
- 手动开票直接进入创建订单；可添加多个开票项目。名称/数量同行展示，每项蓝色编辑、红色删除，外层只填项目总价。编辑为独立完整页面，数量/合计金额单位跟随数字；保存同步、取消/返回保留整单草稿。金额只汇总各行总价，不乘数量。
- 订单编号仅英文字母和数字，最多36个字符，可手输/扫码；留空自动分配，手填保持原值。旧Demo空号稳定补齐，系统分配格式仅示意。超长/非法扫码拒绝而不截取覆盖。备注最多200个字符（中文按一个字符计），兼容中文输入法。编号规则、备注上限及字数计数不默认显示；非法或超长草稿保留供修正，保存被拦截，错误只在对应字段下显示、修正后消失。项目金额逐项在金额字段下提示，编辑页数量和金额分别提示，空项目提示位于添加按钮下；订单日期默认上海当天，可修改，业务含义为实际销售完成日期。
- 创建/修改后进入订单开票详情。顶部合并开票金额、状态和可用二维码；不显示内部开票订单号、发票号码字段、放大按钮及处理记录。实际票面预览仍有发票号码。
- 未开票：导航栏右上撤销，底部固定修改/打印二维码。开票中：仅底部查询开票结果，状态更新入口也禁止撤销。有效已开票：导航栏无撤销，底部固定整单退票/重发邮件；整单退票二次确认后执行全额红冲。
- 撤销使二维码失效，已开发票全额红冲。已取消详情主状态仅“已取消”，去掉顶部重复“订单已撤销”和无票时的二维码失效提示；全额红冲完成后不再显示成功说明卡片；红冲处理中和失败说明保留。已取消无继续开票/重发操作。既有历史撤销后晚到出票自动红冲兜底保留。
- 记录与退票查询共用四字段卡片：订单编号、开票金额、订单日期、状态；无商品/创建时间/查看文字。未申请状态显示“未申请”，取消仅“已取消”。分类仅全部/未申请/开票中/已开票，取消记录仍在全部。
- 默认查本设备，输入订单号可跨本机/本店/其他门店查询；不展示范围辅助文案。记录查询占位“输入订单编号查询”；退票初始引导“请输入订单编号查询已开票记录”。退票结果进入同一详情，返回退票页。
- 同一扫码组件用于创建、修改和退票查询：设备扫码枪回车、受支持浏览器摄像头和外置评审模拟结果。只在扫码界面开启时接收，关闭清理轮询/媒体；创建/修改仅回填编号，不清草稿、不自动提交。
- 已开票点击重发邮件进入独立邮箱页面，允许修改接收邮箱、校验后提交。仅本地模拟投递，详情显示本次邮箱，原申请快照不覆盖；未开票、已取消或红冲中均禁止发送，提交时复核最新状态。
- 部分退货通过撤销原订单后独立新建剩余消费承接，不自动关联新旧订单。

## 状态样例

默认补充3条开票中订单：`XS20261115P001`（268元）、`XS20261115P002`（598元）、`XS20261115P003`（1280元）。本设备记录的开票中分类可直接查看；样例不随计时自动出票，查询保持开票中，可在评审入口选中后点击推进出票。已有本地数据只增量补入一次，不重置自建订单或已操作样例。

## 二维码小票

按用户参考图：品牌Logo、中英扫码提示/本次金额、大申请二维码、门店名称、门店编号、订单编号及其Code128条码、设备编号、订单日期。无开票流水号及打印时间。底部“收钱吧提供技术服务支持。”。条码直接编码订单编号，不编码内部流水号；已独立验证手填123123、含前导零与自动编号的解码一致性。58mm打印输出有支持标识，排除临时Toast。

## 演示边界

不设计/修改既有C端；本次新增门店手动开票配置，不展开其他后台能力、店员代填抬头、操作密码、打印联数或超期协助。项目清单可按品牌统一配置，也可由门店单独配置覆盖。

二维码仅编码订单标识，既有C端地址/服务、真实开票/mapping/邮件、POS扫码SDK及真实打印机未接入。支持的浏览器可申请摄像头，但未做实机识码验证。卖方税号、13%税率、购方及发票为虚构演示，不代表真实配置。字段未来日期限制、修改后旧码失效等此前注明的演示假设保留；生产自动编号格式和打印密度适配待核对。旧Demo记录不因本次字符规则而删除，重新保存时按最新规则校验。

## 门店手动开票配置（2026-11-16）

- CRM：品牌零售订单开票设置 → 门店开票设置。品牌统一项目在列表上方；每行新增门店手动开票状态和设置入口。门店配置单独项目后仅用门店项目，选回品牌统一项目后恢复继承。
- 只有门店可开票时才能开启手动开票；不可开票时设置开关禁用，门店端同时校验。Demo在门店失去开票资格时关闭手动开票，重新可开票后需重新启用；此处不替代生产配置状态机。
- POS 设置 → 应用功能 → H5 应用设置 → 电子发票，仅控制入口显隐。入口展示时，未开通门店点击后显示“功能未开通”。
- 项目字段为项目名称、商品大类、计量单位、规格型号；税编/税率沿用该品牌已有商品大类匹配规则，不再独立采集。字段及生产API待研发核对；本次为可评审Demo。
- `review.html` 可选择已配置的品牌/门店，并打开两处配置页；同源页面在同一浏览器内共享模拟配置。原悦投样例为预置已开通门店，保留原有订单样例。
- 本地配置页：`admin/crm/index.html#manual-invoice`、`admin/pos-settings.html`。项目选择、存量订单项目快照、开关和入口联动均仅为浏览器本地模拟，不调用CRM、发票或POS生产服务。
